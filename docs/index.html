TRAIL Learning Task-Relevant Latent Residuals
for Robot Manipulation

TRAIL turns prediction into an explicit control signal. It learns task-relevant visual dynamics from action-free human videos, retains the intent predictor at deployment, and exposes the predicted latent change to the robot policy.

Overview

Prediction that stays useful at deployment

Learning language-conditioned robot manipulation policies requires representations that capture not only the current scene but also how it changes under task instructions. While general-purpose visual representations have improved robotic perception, they mainly encode static scenes and provide limited guidance about the temporal dynamics relevant to action.

TRAIL learns task-relevant temporal dynamics as latent residuals through an information-access bottleneck. A shared future predictor runs with and without direct access to dense patch tokens; the intent stream is distilled from the full-information stream so that prediction emphasizes changes associated with the instruction. During policy learning, TRAIL retains this predictor and computes an explicit latent residual between the current observation and predicted future state. This lightweight, control-oriented context improves policy learning across simulation and real-robot manipulation.

Approach

Learn the change.
Keep the predictor.

The same shared predictor is trained under asymmetric information access. This creates a compact intent stream that can be retained as policy context instead of being discarded after pre-training.

Where does the gain come from?

Qualitative grounding checks whether language selects relevant visual evidence; stage-level evaluation shows where policies make progress on dynamic manipulation.

Core idea

Do not ask the downstream policy to rediscover temporal structure from a static feature. Give it the predicted, task-relevant change directly.
