\section{Introduction}

Robot learning is increasingly important to build autonomous systems that operate in unstructured and unseen environments. Learning robot manipulation policies fundamentally requires rich, structured representations that capture object semantics and geometry, spatial relationships, dynamics, and task-relevant affordances. However, learning such representations without extensive manual supervision remains a fundamental challenge.

Recent advances in self-supervised representation learning have enabled general-purpose models, such as DINO~\cite{caron2021emerging}, R3M~\cite{nair2022r3m}, and VIP~\cite{ma2022vip}, which provide transferrable features for robotic perception and manipulation. These models improve robots' ability to extract semantically meaningful information from the scene.
However, these representations are fundamentally static, as they are learned to characterize the current state of the scene (\textit{what is in the scene}), rather than capturing temporal transition (\textit{how the world is changed}). In result, downstream control policies are required to learn the capability of inferring task-relevant dynamics and physical transitions, implicitly discovering which visual changes are critical to task completion. 
This separation between perception and dynamics understanding forces policies to re-learn, from scratch, the temporal structure that is essential for manipulation~\cite{hewage2020temporal,zakka2022xirl}.

This separation between perception and dynamics understanding forces policies to re-learn, from scratch, the temporal structure that is essential for manipulation.

Learning predictive representations offers a natural solution by introducing a temporal structure through future-state forecasting. By learning to predict the future state, a model can capture the dynamics that policies need~\cite{hafner2019dream,finn2017deep}. However, existing approaches show two critical limitations. First, many approaches rely on computationally heavy pixel-level reconstructions~\cite{he2022masked, gupta2023siamese, zhu2025lava, zeng2024learning, karamcheti2023language,kim2025token}, forcing models to allocate a capacity to learn high-frequency visual details that might be irrelevant to operating robotic tasks. This entangles manipulation-induced object motion with passive dynamics or environmental noise. \rev{Second, the temporal knowledge acquired during pre-training is not carried into policy learning. For predictive models this is literal: the decoder is discarded once pre-training ends~\cite{radosavovic2023real, xiao2022masked}. For models whose temporal signal comes from the training objective rather than from a decoder --- such as the time-contrastive R3M~\cite{nair2022r3m} --- nothing is thrown away, but the temporal structure survives only implicitly, compressed into a static embedding. In both cases the policy is handed features that describe the present (Fig.~\ref{fig:teaser}, top) and must re-identify, from scratch, which visual changes are the ones that matter.}

In this work, we hypothesize that predictive learning should not be treated only as a pre-training task that will be discarded, but rather as a mechanism for extracting \textit{intent-aligned state transitions} directly within the latent space. Instead of predicting all future environmental changes, we focus on identifying specific future states that align with the intended task.

We present LARM (\textbf{L}earning Intent-\textbf{A}ligned Latent Residuals for Language-Conditioned \textbf{R}obotic \textbf{M}anipulation), a self-supervised representation learning framework that constrains future latent representations using task semantics derived from an image and language instructions.  
\rev{Specifically, LARM runs a single future predictor under two different levels of access to the current frame. One pass reads the dense visual features of the scene; the other sees the scene only through a single language-grounded global token, so that it can only forecast what the instruction itself accounts for. By distilling the first prediction into the second, the model learns to filter out irrelevant background or passive movements and to focus on the visual changes that are directly related to the robot executing the target manipulation task.}


At deployment, we use LARM's predictive module to compute a lightweight latent residual between the current observation and the future state (Fig.~\ref{fig:teaser}, bottom). This residual directly captures intent-aligned changes specified by the language-based task description. This residual provides an explicit directional signal, which simplifies the policy's objective to follow a clear, step-by-step latent trajectory rather than inferring task priorities from complex observations. Consequently, the predictor actively guides downstream control rather than merely serving as a standalone pre-training objective.

We summarize our contributions as follows:
\begin{itemize}
\item We introduce an asymmetric predictive representation learning framework that extracts intent-aligned dynamics in latent space. \rev{The asymmetry is an information-access bottleneck: one and the same predictor is run with and without dense spatial memory, and the bottlenecked pass is distilled from the other.} Our latent-space learning naturally encourages the model to focus on task-relevant changes without requiring explicit supervision.

\item We show that utilizing the predictor is beneficial, by demonstrating that the intent-aware latent residuals ($\Delta_z$) can serve as a lightweight, effective control prior that improves policy precision and robustness.
\item We validate our model on \rev{two simulation benchmarks, Franka Kitchen~\cite{franka_kitchen} and the ten-task Meta-World MT10 suite~\cite{yu2020meta},} and across 7 different real-robot manipulation tasks, where our model consistently outperforms existing models.
\end{itemize}
