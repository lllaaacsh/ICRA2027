\section{Introduction}

Robot manipulation requires visual representations that describe not only what is currently visible, but also how the scene should change for a task to succeed. Recent self-supervised representation learners, including DINO~\cite{caron2021emerging}, R3M~\cite{nair2022r3m}, and VIP~\cite{ma2022vip}, have made frozen visual features increasingly useful for robotic perception and control. However, manipulation is inherently temporal: a policy must decide which object motion, contact event, or configuration change matters next. Learning this temporal structure without robot-specific pre-training data or dense manual supervision remains a central challenge~\cite{schmidt2024learning,ye2025latent}.

The main limitation of many general-purpose robot representations is that their temporal knowledge is either absent or only implicit. Static visual features characterize the current scene, but they do not directly tell the policy how the scene is expected to evolve under the task. As a result, downstream controllers must infer task-relevant dynamics and physical transitions from limited demonstrations, effectively relearning temporal structure that is essential for manipulation~\cite{hewage2020temporal,zakka2022xirl}. This burden is especially problematic for long-horizon manipulation, where a small visual change can determine whether the next action should reach, push, open, or place. Fig.~\ref{fig:teaser} contrasts this static representation with Trail's explicit latent change signal.

Predictive representation learning is a natural way to introduce temporal structure, but existing predictive pipelines do not directly expose a control-oriented change signal to the policy. Future prediction has long been used to learn dynamics useful for decision making~\cite{hafner2019dream,finn2017deep}. In vision-based representation learning, many methods train by reconstructing or predicting future visual content~\cite{he2022masked,gupta2023siamese,zhu2025lava,zeng2024learning,karamcheti2023language,kim2025token}. Such objectives can allocate capacity to visual details that are not decisive for manipulation. More importantly, the temporal component is often discarded or compressed after pre-training: predictive decoders may be removed before downstream learning~\cite{radosavovic2023real,xiao2022masked}, while objectives such as time-contrastive learning in R3M~\cite{nair2022r3m} leave temporal information only implicitly inside a static embedding. The root technical problem is therefore not simply how to learn future prediction, but how to retain the task-relevant part of prediction as an explicit policy input.

We propose Trail, a self-supervised framework that learns a task-relevant latent change predictor from action-free human videos. Trail defines current and future states in a frozen DINOv3 feature space and trains a shared future predictor under two information-access conditions. A full-information pass directly reads dense patch tokens, whereas a bottlenecked pass removes this direct dense-patch access and relies on a task-relevant global summary and grounded language context. Distilling the full-information prediction into the bottlenecked prediction encourages the retained branch to forecast the part of the future that is recoverable from task context, rather than generic background motion or passive scene changes.

At deployment, Trail turns prediction into a residual-guided policy representation. The retained bottlenecked predictor is executed at every control step, producing a task-relevant latent forecast in the same feature space as the current observation. Trail then computes the token-wise latent residual $\Delta_z$ between the forecast and the current state, and feeds both the current state and this residual to the downstream policy. This design differs from using an absolute future feature alone: the residual makes the direction of task progress explicit, so the action decoder does not need to infer the difference between present and predicted states internally.

Our experiments evaluate whether this retained latent residual improves downstream control under fixed policy-learning protocols. On Franka Kitchen~\cite{franka_kitchen}, Trail achieves the highest average success rate among the compared frozen-representation and predictive baselines. On Meta-World MT10~\cite{yu2020meta}, Trail again obtains the strongest average result, with the clearest gains on tasks where object motion makes the next action depend on how the scene is changing. In real-robot tabletop manipulation, Trail improves average success over CLIPort~\cite{shridhar2022cliport}, MPI~\cite{zeng2024learning}, and LaVA-Man~\cite{zhu2025lava}, with strong results on held-out objects and contact-rich pushing tasks. These results support the following contributions:

\begin{itemize}
    \item We introduce an asymmetric predictive representation learning framework that learns task-relevant latent dynamics from action-free human videos, without robot pre-training data or dense manual supervision.
    \item We retain the predictor after pre-training and convert its output into an explicit latent residual $\Delta_z$, giving downstream policies a task-relevant direction of change rather than only a static state descriptor.
    \item We validate the representation across Franka Kitchen~\cite{franka_kitchen}, Meta-World MT10~\cite{yu2020meta}, residual design ablation and across 7 different real-robot manipulation tasks, where our model consistently outperforms
existing models.
\end{itemize}
