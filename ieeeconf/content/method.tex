\section{Method}
\label{sec:method}

\subsection{Overview}
\label{subsec:method_overview}

Trail learns a task-relevant latent change predictor from action-free human videos and then uses the predicted change as policy context. The method has two stages. During pre-training, a language-grounded encoder and an asymmetric predictor learn to forecast frozen DINOv3 future tokens from Kinetics videos without robot actions (Sec.~\ref{subsec:notation}--\ref{subsec:training_objective}). During downstream imitation learning, the retained predictor runs in the robot control loop and produces a latent residual, which is scale-normalised before conditioning the policy (Sec.~\ref{subsec:policy_learning}--\ref{subsec:deployment}). The full-information branch provides a pre-training target, whereas the bottlenecked branch is retained for downstream control. Fig.~\ref{fig:ab_probe} summarizes the architecture.

\subsection{Latent Space}
\label{subsec:notation}

Trail defines current and future states in the same frozen feature space. A frozen DINOv3 visual encoder~\cite{simeoni2025dinov3} maps the current RGB frame to tokens $z_t=[v_{\texttt{cls}},v_{1:N}]$ and the future frame to the stopped training target $z^{\mathrm{gt}}_{t+k}$. A frozen DistilBERT encoder~\cite{sanh2019distilbert}, followed by a trainable projection to the visual feature width, maps the instruction to language tokens. At $224\times224$ resolution, $z_t$ contains one visual class token and $N=196$ patch tokens. Throughout the paper, \texttt{[CLS]} refers only to this visual class token. The offset $k$ is a web-video pre-training gap, not a robot control horizon.

\subsection{Language-Grounded Visual Encoding}
\label{subsec:encoder}

The first module grounds the current visual state in the instruction before future prediction. The visual tokens first query the language tokens through cross-attention with a residual connection, making both the class and patch tokens instruction-conditioned. The language tokens then query these updated visual tokens, incorporating the current scene into the language context. We denote the resulting visual tokens by $z'_t=[v'_{\texttt{cls}},v'_{1:N}]$ and the contextualized language tokens by $L'$. The visual class token provides a compact task-relevant summary, while the patch tokens preserve dense spatial evidence.

\subsection{Asymmetric Bottlenecked Prediction}
\label{subsec:pretraing}

The second module separates task-relevant future prediction from generic video extrapolation. Trail evaluates the same predictor under two memory-access conditions. Let $P$ denote the shared predictor and $Q$ its $N{+}1$ learned, content-free future queries. The two passes are

\begin{align}
\hat z^{\mathrm{full}}_{t+k}
    &=P\!\left(Q\mid[z'_t,L']\right), \label{eq:full_stream}\\
\hat z^{\mathrm{int}}_{t+k}
    &=P\!\left(Q\mid[v'_{\texttt{cls}},L']\right). \label{eq:int_stream}
\end{align}

The full-information stream in Eq.~\ref{eq:full_stream} therefore reads both the class and dense patch tokens, whereas the bottlenecked stream in Eq.~\ref{eq:int_stream} has no direct access to $v'_{1:N}$. We use the superscript $\mathrm{int}$ for this retained, instruction-conditioned prediction. The bottleneck changes only memory access: both streams share $P$ and $Q$, execute the same operations, and emit $N{+}1$ future tokens.

\subsection{Training Objective and Gradient Flow}
\label{subsec:training_objective}

Both predictions are supervised against the same frozen future target. The full and intent prediction losses each combine mean-squared error with cosine distance, while a third loss transfers the full-information forecast to the intent stream:

\begin{align}
\mathcal{L}_{\mathrm{full}}
    &=\operatorname{MSE}\!\left(\hat z^{\mathrm{full}}_{t+k},z^{\mathrm{gt}}_{t+k}\right) \notag\\
    &\quad+1-\operatorname{cos}\!\left(\hat z^{\mathrm{full}}_{t+k},z^{\mathrm{gt}}_{t+k}\right),
      \label{eq:loss_full}\\
\mathcal{L}_{\mathrm{int}}
    &=\operatorname{MSE}\!\left(\hat z^{\mathrm{int}}_{t+k},z^{\mathrm{gt}}_{t+k}\right) \notag\\
    &\quad+1-\operatorname{cos}\!\left(\hat z^{\mathrm{int}}_{t+k},z^{\mathrm{gt}}_{t+k}\right),
      \label{eq:loss_int}\\
\mathcal{L}_{\mathrm{cons}}
    &=\left\|\hat z^{\mathrm{int}}_{t+k}
      -\operatorname{sg}\!\left(\hat z^{\mathrm{full}}_{t+k}\right)\right\|_2^2.
      \label{eq:loss_cons}
\end{align}

In Eqs.~\ref{eq:loss_full}--\ref{eq:loss_cons}, MSE and cosine similarity are averaged over corresponding future tokens, and $\operatorname{sg}(\cdot)$ denotes stop-gradient. The complete objective is

\begin{equation}
\mathcal{L}_{\mathrm{total}}
=\mathcal{L}_{\mathrm{full}}
+\mathcal{L}_{\mathrm{int}}
+\alpha\mathcal{L}_{\mathrm{cons}}.
\label{eq:total}
\end{equation}

The weight $\alpha$ controls the consistency term, and we empirically set $\alpha=0.3$. This term sends gradients only through the intent stream, distilling the full-information forecast without updating it as a target. The frozen visual and language backbones contribute no gradient path, while the language projection, fusion module, future queries, and predictor are shared and trainable. Algorithm~\ref{alg:pretrain} summarizes the procedure.

\begin{algorithm}[t]
\caption{Trail pre-training step}
\label{alg:pretrain}
\begin{algorithmic}[1]
\State encode the current frame with frozen DINOv3
\State encode the instruction with frozen DistilBERT and project it
\State fuse the visual and language tokens with bidirectional cross-attention
\State encode the future frame as the stopped target $z^{\mathrm{gt}}_{t+k}$
\State $\hat z^{\text{full}}_{t+k} \gets$ shared predictor with all fused visual tokens
\State $\hat z^{\text{int}}_{t+k} \gets$ shared predictor with class and language tokens
\Statex \hfill \Comment{no direct patch access}
\State compute the three losses and $\mathcal{L}_{\mathrm{total}}$ using Eqs.~\ref{eq:loss_full}--\ref{eq:total}
\State update the projection, fusion module, future queries, and shared predictor
\end{algorithmic}
\end{algorithm}

\subsection{Residual-guided policy learning}
\label{subsec:policy_learning}

The downstream policy needs a control-oriented signal rather than a reconstructed future image. After pre-training, the full-information stream is dropped and the bottlenecked predictor is retained. Given the current observation and instruction, it produces the intent prediction $\hat z^{\mathrm{int}}_t$ in the same frozen DINOv3 feature space as $z_t$. Trail forms the token-wise residual

\begin{equation}
    \Delta_z = \hat z^{\mathrm{int}}_t-z_t. \label{eq:residual}
\end{equation}

The residual exposes the predicted change from the current latent state, so the policy receives both where the scene is now and how the bottlenecked predictor expects it to change. Unlike an absolute future feature, this representation makes the difference between current and predicted states explicit rather than leaving the policy to infer that difference internally.

\noindent\textbf{Residual scale balancing.}
Because the residual can have a smaller magnitude than the current-state features, we normalize the two token sequences independently before policy readout. This prevents a simple scale difference from suppressing the residual during fusion. Behavioral cloning then predicts the action from the balanced state and residual features together with proprioception. Low-dimensional control uses a vector readout, whereas spatial affordance policies use a patch-map readout. Table~\ref{tab:ablation_residual} compares this residual context with the current state alone, the predicted future alone, and the absolute current--future pair. \subsection{Deployment}
\label{subsec:deployment}

The predictor is executed at every control step in closed loop. The robot observes the current image, encodes it with the instruction, runs the retained bottlenecked predictor once, computes $\Delta_z$, balances the state and residual feature scales, and then predicts an action; the same process repeats after the robot moves. The predictor is not rolled out over multiple future steps and is not run only once at the beginning of an episode. This directly separates the pre-training gap $k$ from the control frequency: $k$ defines the web-video target used to learn a directional residual, while the action decoder learns the magnitude and time scale of robot actions from labeled demonstrations.

The retained predictor emits one future class token and a sequence of future patch tokens aligned one-to-one with the frozen DINOv3 teacher. Eq.~\ref{eq:residual} is therefore applied token-wise, and $\Delta_z$ retains spatial structure. This single output supports both action spaces we consider, with different read-outs. For \textit{1-D continuous control} that predicts joint angles or end-effector poses~\cite{assran2025v}, we concatenate the \texttt{[CLS]} residual with the current-state features and proprioception as input to a multi-layer perceptron policy. For \textit{2-D spatial-action policies} designed for vision-based affordance models (e.g.\ tabletop pick-and-place~\cite{shridhar2022cliport}), we reshape the patch residuals into a spatial map and fuse it with the policy's visual backbone via convolutional layers, providing an explicit prior on where and how to interact. In both cases the predictor is unchanged; only the read-out differs, which allows Trail to integrate with low-dimensional state policies and high-dimensional visuomotor architectures without architectural modification.
